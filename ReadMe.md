# Stock Exchange Simulator

## About

Stock Exchange Simulator is a C++ project that simulates how a stock exchange works. Users can create an account, log in, buy and sell stocks, manage their portfolio, and view their trading history.

I started this project to learn how trading systems work and to improve my understanding of Data Structures and Algorithms by applying them to a real-world problem. Through this project, I am working with concepts such as Priority Queues, Heaps, Hash Maps, Vectors, File Handling, and Object-Oriented Programming.

The goal of this project is to gain hands-on experience in building a complete application from scratch while strengthening my problem-solving and software development skills.
